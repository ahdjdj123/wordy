# WORDY

### Explore words. Experiment with ideas.

Wordy is an interactive vocabulary experience designed to make exploring language more engaging, intuitive and creative.

Rather than presenting words as simple definitions to memorise, Wordy offers an interactive environment where users can discover vocabulary, experiment with words and explore different ways of engaging with language.

## ✨ About the Project

Wordy explores a simple idea: vocabulary learning does not have to be limited to reading definitions and memorising words.

The project brings together interactive elements and creative exploration to offer a more engaging experience with language.

Its goal is to create an environment where users can discover, experiment with and revisit words through different activities.

## 🎯 Project Philosophy

Wordy is built around three principles:

- **Exploration:** Make discovering words engaging.
- **Interaction:** Encourage users to actively engage with language.
- **Creativity:** Treat vocabulary as something to experiment with, not merely memorise.

The project is intended to remain an independent, evolving educational and creative experience.
